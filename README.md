Задание A3
Условие: Число 3 в степени 9090001 займет в памяти компьютера 1921000 байт. Напишите программу, которая вычисляет сколько это мегабайт. В одном килобайте – 1024 байта, в одном мегабайте – 1024 килобайта.
Проверьте свой результат, воспользовавшись функцией getsizeof() из модуля sys. Для этого необходимо выполнить импорт модуля sys в вашу программу. Функция возвращает размер объекта в байтах. Ваш объект – это число 3 в степени 9090001. Придется несколько подождать, пока функция вернет результат.
